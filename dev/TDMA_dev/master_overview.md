# TDMA IP — 설계 개요

> 버전: 0.2 (초안)
> 작성일: 2026-05-16

---

## 1. 목적

본 문서는 단일 케이블 환경에서 동작하는 TDMA 기반 통신 IP의 설계 개요를 기술한다. IP는 마스터와 슬레이브 두 종류로 구성되며, 열악한 물리 환경에서도 동작 가능하도록 저속·단순 구조를 지향한다. PTP 시간동기화와 기본적인 내고장성 처리를 포함한다.

---

## 2. 주요 특성

| 항목 | 내용 |
|------|------|
| 토폴로지 | Star (마스터 1 : 슬레이브 최대 7) |
| 매체 | 단일 케이블 (열악한 환경 가정) |
| 통신 방식 | TDMA — 슬롯당 슬레이브 1개 할당 |
| 최대 슬레이브 수 | 7개 (슬레이브 주소 1~7, 주소 0 = 루프백) |
| 기준 클럭 | 장치 독립 (외부 클럭 입력) |
| 클럭 분주 | 프리스케일러 10비트, 1~1024 분주 |
| 시간동기 | PTP four-timestamp (T1~T4) |
| 내고장성 | fault 카운터 기반 격리 및 자동 복구 |
| 레지스터 인터페이스 | 32비트 폭, 장치 독립적 설계 |
| 엔디언 | little-endian |

## 3. 기능 요약

### 3.1 TDMA 슬롯 관리

마스터는 활성 슬레이브 수(NODE_CNT)에 따라 TDMA 사이클을 구성한다. 각 사이클은 슬레이브 수만큼의 슬롯으로 이루어지며, 슬롯 0은 루프백 슬롯으로 항상 예약된다.

슬롯 내 프레임 구조:

```
[preamble 8비트] [payload 32비트] [T1 + 종료신호 32비트] [guard time] [마스터 답신: T2·T3] [guard time]
```

- preamble: 0x55 (10101010) 고정, 경계 감지용
- payload: 슬레이브 센서값 32비트
- T1: 슬레이브 송신 타임스탬프 (슬레이브가 payload에 포함하여 전송)
- guard time: LINK_CFG.GUARD_TICKS로 설정, 마스터 처리 여유 확보
- 마스터 답신: T2(마스터 수신 타임스탬프) + T3(마스터 송신 타임스탬프) 포함

### 3.2 PTP 시간동기화

슬롯마다 four-timestamp 방식으로 시간동기를 수행한다.

| 타임스탬프 | 설명 | 캡처 주체 |
|-----------|------|-----------|
| T1 | 슬레이브 송신 시점 | 슬레이브 |
| T2 | 마스터 수신 시점 | 마스터 |
| T3 | 마스터 답신 송신 시점 | 마스터 |
| T4 | 슬레이브 수신 시점 | 슬레이브 (다음 슬롯에 전달) |

보정값 계산:

```
offset = ((T2 - T1) - (T4 - T3)) / 2
delay  = ((T2 - T1) + (T4 - T3)) / 2
```

T1~T4는 모두 동일한 N클럭 지연 후 캡처하여 차분 계산 시 지연이 상쇄된다.

### 3.3 내고장성

fault를 세 종류로 분류한다:

| 종류 | 조건 |
|------|------|
| 경계위반 (PREAMBLE_ERR) | 슬롯 시작 시 preamble(0x55) 미수신 |
| 문법오류 (FRAME_ERR) | preamble 수신 후 프레임 구조 오류 |
| CRC 오류 (CRC_ERR) | payload CRC 불일치 |

fault 카운터가 FAULT_TH에 도달하면 해당 노드를 fault 상태로 격리한다. 격리 이후 연속 성공 횟수가 RECOVERY_TH에 도달하면 정상 상태로 복구한다. 임계값은 NODE_CFG 레지스터로 설정 가능하다.

### 3.4 루프백

슬레이브 주소 0번 슬롯은 항상 루프백으로 동작한다. 마스터 송신 경로를 수신 경로로 되돌려 통신 하드웨어 자가진단에 사용한다.

## 5. 마스터 / 슬레이브 구성 비교

마스터와 슬레이브는 CTRL, LINK_CFG, IRQ 구조를 공유하며, 역할에 따라 레지스터 구성이 달라진다.

| 항목 | 마스터 | 슬레이브 |
|------|--------|----------|
| 레지스터 수 | 49개 | 11개 |
| 노드 설정 | NODE_CFG (NODE_CNT, FAULT_TH, RECOVERY_TH) | SLAVE_CFG (SLAVE_ADDR) |
| 데이터 방향 | 수신 전용 (NODE_DATA×7) | 송신 전용 (TX_DATA) |
| 상태 관리 | 노드별 NODE_STATUS×7, GLOBAL_STATUS | 자기 슬롯 RX_STATUS 하나 |
| PTP 타임스탬프 | T1~T4 × 7노드 | T1~T4 × 1 (자기 슬롯) |
| 내고장성 | 노드별 fault 카운터, 격리/복구 | 마스터 답신 오류 감지만 |
| 루프백 | 슬롯 0 하드와이어드 | 해당 없음 |
| CYCLE_CNT | 있음 | 없음 |
