# TDMA IP — 물리 계층 설계 결정 근거

> 버전: 0.3
> 작성일: 2026-05-21
> 비고: 테스트 HW 고정 사양(기준 클럭, 케이블 길이, 토폴로지)은 제외. 설계 선택 항목만 기술.

---

## 1. TX / RX 케이블 분리 (단방향 이중 케이블)

**결정**: 마스터↔슬레이브 간 케이블을 TX 전용, RX 전용으로 분리한다.

- **TX 케이블**: 마스터 → 전체 슬레이브 브로드캐스트 전용선. 슬레이브 수만큼 분기하거나 버스 형태로 구성.
- **RX 케이블**: 전체 슬레이브가 공유하는 단일 버스 → 마스터. 각 슬레이브는 자신의 TDMA 슬롯에서만 버스를 구동한다.

**근거**:
- TX/RX를 단일 케이블 반이중으로 구성하면 송수신 전환 타이밍을 명시적으로 제어해야 한다. 전환 지연이 슬롯 타이밍 설계를 복잡하게 만든다.
- TX/RX 분리 시 마스터 틱 브로드캐스트(TX)와 슬레이브 전송(RX)이 동시에 발생할 수 있다. 사이클 시작 시점에 두 동작을 겹치는 설계가 가능해진다.
- RX를 공유 버스로 구성하면 슬레이브 수와 무관하게 배선이 단순해진다.

---

## 2. 공유 RX 버스 설계 (TDMA + High-Z)

**결정**: 모든 슬레이브가 단일 RX 버스를 공유한다. 슬레이브는 자신의 TDMA 슬롯에서만 버스를 구동하고, 그 외 구간에서는 출력을 High-Z로 전환한다.

**근거**:

| 요소         | 역할                                                                                     |
| ---------- | -------------------------------------------------------------------------------------- |
| TDMA 슬롯 분리 | 어느 시점에도 최대 1개의 슬레이브만 버스를 구동하므로 충돌이 발생하지 않는다. 별도 충돌 감지·중재 로직이 불필요하다.                    |
| High-Z 아이들 | 슬롯 외 구간에서 드라이버가 High-Z로 전환되어 버스를 개방한다. 여러 드라이버가 동시에 연결되어 있어도 능동 구동하지 않으면 서로 간섭하지 않는다.  |
| ADDR 필드    | 공유 버스에서 마스터는 수신 프레임의 addr 필드로 송신 슬레이브를 식별한다. 슬롯 번호와 addr 불일치는 타이밍 오류(슬롯 침범) 감지 수단이 된다. |

공유 버스 구성에서 High-Z는 선택 사항이 아닌 동작의 전제 조건이다. 한 슬레이브라도 슬롯 외 구간에 능동 구동하면 버스 경합이 발생하여 다른 슬레이브의 전송이 손상된다.

RX 버스의 LINE_FAULT는 물리적으로 버스 전체에 영향을 미친다. 배선 단절·단락 등 버스 수준의 장애가 발생하면 모든 슬레이브 슬롯이 동시에 영향받는 패턴으로 식별된다. 상세 fault 처리는 `04_fault_decisions.md` 참조.

## 3. 비트 인코딩: Manchester

**결정**: NRZ 대신 Manchester 인코딩을 사용한다.

**근거**:
- Manchester는 비트 중간에 반드시 전이가 발생하므로 수신 측이 별도 클럭 선 없이 비트 타이밍을 복원할 수 있다(셀프 클로킹).
- 각 노드가 독립 크리스탈 클럭을 사용하는 구성에서, 클럭 복원 없이는 수신 측 샘플링 오류가 발생한다. Manchester가 이를 해소한다.
- NRZ 대비 대역폭을 2배 소모하나, 목표 전송 속도(125 kbps)와 기준 클럭(25 MHz) 기준으로 심볼당 클럭 마진이 충분하여 문제가 없다.
- Verilog 구현 난이도가 낮다. TX는 클럭 반 주기마다 신호를 반전하는 로직, RX는 비트 중간 전이를 감지하는 로직으로 수십 줄 수준에서 구현 가능하다.
- 차동 Manchester, 4B5B 등 대안 대비 인코딩/디코딩 테이블이나 추가 상태가 필요 없어 실습 구현에 가장 적합하다.

---

## 4. 아이들 상태: High-Z / 종단 저항 없음

**결정**: 드라이버가 전송하지 않을 때 출력을 High-Z(삼상 개방)로 전환한다. 별도 종단 저항을 배치하지 않는다.

**근거**:

| 목적 | 설명 |
|------|------|
| 공유 버스 구동 조건 | 슬롯 외 구간에서 High-Z로 전환해야 다른 슬레이브가 버스를 구동할 수 있다. High-Z 없이는 공유 버스 구성 자체가 불가능하다. |
| 드라이버 단순화 | 아이들 값을 유지하는 별도 로직 없이 삼상 버퍼 인에이블 제어만으로 구현된다. |

**종단 저항 불필요 판단**: 50cm 단거리, 125kbps 저속, Manchester 인코딩 조합에서 전파 지연과 반사파는 1클럭(40ns) 이내로 수렴한다. 아이들 float 구간의 노이즈가 preamble(0x55) 패턴으로 오인될 가능성이 낮고, Hamming 1비트 정정이 추가로 보호한다. ESD 보호가 필요한 경우 케이블 양단에 직렬 22Ω을 추가할 수 있으나 타이밍 계산에 영향을 주지 않는다.

**라인 이상 감지**: 슬레이브 드라이버 고장 또는 버스 단절 시 해당 슬롯에서 Manchester 전이가 발생하지 않는다. 수신 측은 예상 슬롯 내에 preamble(0x55)이 감지되지 않으면 LINE_FAULT 카운터를 증가시킨다. 유효 신호 존재 여부를 판단 기준으로 삼는다.
