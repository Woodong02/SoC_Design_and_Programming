# TDMA-PTP Master IP — 레지스터 맵 사양

> 버전: 0.1 (초안) · 데이터 폭: 32비트 · 주소 폭: 32비트 · 엔디언: little-endian
> 기준 클럭: 25 MHz · 최대 슬레이브: 7개 (주소 1~7) · 슬레이브 0 = 루프백

---

## 표기 규칙

| 기호 | 의미 |
|------|------|
| RO | 읽기 전용 |
| RW | 읽기/쓰기 |
| W1C | 쓰기 1로 클리어 |
| RC | 읽기로 클리어 |
| reserved | 0으로 읽힘, 쓰기 무시 |

---

## 1. 제어 레지스터

### 0x00 — CTRL

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | ENABLE | RW | 0 | 1: IP 동작 시작 |
| 1 | SOFT_RST | RW | 0 | 1: 소프트 리셋 (자동 클리어) |
| 31:2 | reserved | — | 0 | — |

> 슬레이브 0번 슬롯은 항상 루프백으로 하드와이어드.

---

### 0x04 — LINK_CFG

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 9:0 | DIV | RW | 0 | clk_tick = clk / (DIV + 1), 1~1024 분주 |
| 19:10 | GUARD_TICKS | RW | — | guard time 틱 수. 기본값 = 마스터 답신 메시지 분량 틱 + 여유 |
| 31:20 | reserved | — | 0 | — |

> 25 MHz 기준: DIV=0 → 25 Mtick/s, DIV=99 → 250 ktick/s, DIV=1023 → 약 24.4 ktick/s
> 슬롯 구조: [preamble 8비트 고정] [payload 32비트] [T1+종료신호 32비트] [guard time] [마스터 답신: T2·T3] [guard time]
> preamble = 0x55 (10101010) 하드와이어드, payload = 32비트 고정, 타임스탬프 = 32비트

---

### 0x08 — NODE_CFG

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 2:0 | NODE_CNT | RW | 0 | 활성 슬레이브 수. 값 N → 슬레이브 1~(N+1) 활성. 최대 6 (7개) |
| 6:3 | FAULT_TH | RW | 3 | fault 격리 임계값 (0~15) |
| 10:7 | RECOVERY_TH | RW | 3 | 복구 성공 임계값 (0~15) |
| 31:11 | reserved | — | 0 | — |

---

## 2. 노드별 데이터 레지스터 (×7)

기준 주소: `0x10 + (n-1) × 0x04`, n = 1~7

### 0x10 + (n-1)×4 — NODE_DATA[n]

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 31:0 | RX_DATA | RC | 0 | 슬레이브 n의 최근 수신 payload. 읽으면 DATA_VALID 클리어 |

> 주소 목록: NODE_DATA[1]=0x10, [2]=0x14, [3]=0x18, [4]=0x1C, [5]=0x20, [6]=0x24, [7]=0x28

---

## 3. 노드별 상태 레지스터 (×7)

기준 주소: `0x30 + (n-1) × 0x04`, n = 1~7

### 0x30 + (n-1)×4 — NODE_STATUS[n]

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 1:0 | CONN_STATE | RO | 00 | 00=비활성, 01=정상, 10=fault, 11=복구중 |
| 5:2 | FAULT_CNT | RO | 0 | 누적 fault 카운터 (4비트, 0~15) |
| 9:6 | RECOV_CNT | RO | 0 | 복구 성공 카운터 (4비트, 0~15) |
| 10 | DATA_VALID | W1C | 0 | 1: 새 데이터 수신됨. W1C로 클리어 |
| 11 | CRC_ERR | W1C | 0 | 최근 수신 CRC 오류 |
| 12 | PREAMBLE_ERR | W1C | 0 | preamble 경계위반 오류 |
| 13 | FRAME_ERR | W1C | 0 | 문법/프레임 오류 |
| 31:14 | reserved | — | 0 | — |

> 주소 목록: NODE_STATUS[1]=0x30, [2]=0x34, [3]=0x38, [4]=0x3C, [5]=0x40, [6]=0x44, [7]=0x48

---

## 4. PTP 타임스탬프 레지스터 (×7)

기준 주소: `0x50 + (n-1) × 0x10`, n = 1~7
노드당 T1~T4 4개 레지스터 (각 32비트), 총 0x10 간격

### 0x50 + (n-1)×0x10 — NODE_T1[n]

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T1 | RO | 슬레이브 송신 타임스탬프 (슬레이브가 payload에 실어 전송) |

### +0x04 — NODE_T2[n]

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T2 | RO | 마스터 수신 타임스탬프 |

### +0x08 — NODE_T3[n]

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T3 | RO | 마스터 답신 송신 타임스탬프 |

### +0x0C — NODE_T4[n]

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T4 | RO | 슬레이브 수신 타임스탬프 (슬레이브가 다음 슬롯에 실어 전송) |

> 캡처 지연: T1~T4 모두 실제 이벤트 기준 동일한 N클럭 후 캡처. 차분 계산 시 지연 상쇄됨.
> PTP 보정: offset = ((T2-T1)-(T4-T3))/2, delay = ((T2-T1)+(T4-T3))/2

> 주소 목록: NODE_T1~T4[1]=0x50~0x5C, [2]=0x60~0x6C, … [7]=0xA0~0xAC

---

## 5. 글로벌 상태 레지스터

### 0xB0 — GLOBAL_STATUS

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 7:0 | NODE_FAULT_MASK | RO | 0 | 비트 n: 슬레이브 (n+1)이 fault 상태 |
| 8 | BUS_ACTIVE | RO | 0 | 1: TDMA 버스 동작 중 |
| 31:9 | reserved | — | 0 | — |

---

### 0xB4 — CYCLE_CNT

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 31:0 | CYCLE_CNT | RO | 0 | 완료된 TDMA 사이클 수. 래핑 카운터 |

---

## 6. 인터럽트 레지스터

### 0xB8 — IRQ_STATUS

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | CYCLE_DONE | W1C | 0 | TDMA 사이클 1회 완료 |
| 1 | NODE_FAULT | W1C | 0 | 임의 노드 fault 상태 진입 |
| 2 | NODE_RECOVERY | W1C | 0 | 임의 노드 복구 완료 |
| 3 | BUS_ERROR | W1C | 0 | 임의 노드 CRC/프레임/preamble 오류 |
| 4 | PTP_DONE | W1C | 0 | PTP 타임스탬프 갱신 완료 |
| 31:5 | reserved | — | 0 | — |

---

### 0xBC — IRQ_MASK

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | CYCLE_DONE_EN | RW | 0 | 1: CYCLE_DONE IRQ 활성화 |
| 1 | NODE_FAULT_EN | RW | 0 | 1: NODE_FAULT IRQ 활성화 |
| 2 | NODE_RECOVERY_EN | RW | 0 | 1: NODE_RECOVERY IRQ 활성화 |
| 3 | BUS_ERROR_EN | RW | 0 | 1: BUS_ERROR IRQ 활성화 |
| 4 | PTP_DONE_EN | RW | 0 | 1: PTP_DONE IRQ 활성화 |
| 31:5 | reserved | — | 0 | — |

> IRQ 핀 = OR(IRQ_STATUS & IRQ_MASK). 원인 파악: IRQ_STATUS → NODE_FAULT_MASK → NODE_STATUS[n] 순서로 읽기.
