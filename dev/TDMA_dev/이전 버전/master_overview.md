# TDMA IP — 설계 개요

> 버전: 0.3 (초안)
> 작성일: 2026-05-18

---

## 1. 목적

본 문서는 이중 케이블(TX 전용 / RX 전용) 환경에서 동작하는 TDMA 기반 통신 IP의 설계 개요를 기술한다. IP는 마스터와 슬레이브 두 종류로 구성되며, 열악한 물리 환경에서도 동작 가능하도록 저속·단순 구조를 지향한다. 시간동기는 마스터의 틱 브로드캐스트와 슬레이브의 틱 응답을 이용한 단순 오프셋 비교 방식을 사용한다.

---

## 2. 주요 특성

| 항목 | 내용 |
|------|------|
| 토폴로지 | Star (마스터 1 : 슬레이브 최대 8) |
| 매체 | 이중 케이블 — TX 전용 선 / RX 전용 선 (일방통행) |
| 통신 방식 | TDMA — 슬롯당 슬레이브 1개 할당 |
| 최대 슬레이브 수 | 8개 (슬레이브 주소 0~7) |
| 기준 클럭 | 장치 독립 (외부 클럭 입력) |
| 클럭 분주 | 프리스케일러 10비트, 1~1024 분주 |
| 시간동기 | 틱 브로드캐스트 기반 오프셋 비교 |
| 내고장성 | fault 카운터 기반 격리 및 자동 복구 |
| 레지스터 인터페이스 | 32비트 폭, 장치 독립적 설계 |
| 엔디언 | little-endian |

## 3. 기능 요약

### 3.1 TDMA 슬롯 관리

마스터는 활성 슬레이브 수(NODE_CNT)에 따라 TDMA 사이클을 구성한다. 한 사이클은 슬레이브 0번부터 순서대로 각 슬레이브에 하나씩 할당된 타임슬롯으로 이루어진다.

**사이클 구조:**

```
사이클 시작
  │
  ├─ [마스터 틱 브로드캐스트] ← 슬롯 0 시작 시점에 TX 케이블로 전송
  │
  ├─ [슬롯 0: 슬레이브 0 전송] → guard time
  ├─ [슬롯 1: 슬레이브 1 전송] → guard time
  │   ...
  └─ [슬롯 N: 슬레이브 N 전송] → guard time
        ↑ 사이클 완료, 다음 사이클로
```

**슬레이브 슬롯 내 프레임 구조:**

```
[preamble 8비트] [payload 32비트] [CRC] [자기 틱] [종료신호] [guard time]
```

- preamble: 0x55 (10101010) 고정, 경계 감지용
- payload: 슬레이브 센서값 32비트
- CRC: payload와 자기 틱 필드를 포함한 범위에 대해 계산 (다항식 미확정)
- 자기 틱: 슬레이브 로컬 카운터 기준 타임스탬프. 마스터 틱 프레임 내 동일 위치(오프셋)에 맞춰 캡처하여 삽입
- guard time: LINK_CFG.GUARD_TICKS로 설정, 슬롯 간 여유 시간

**마스터 틱 브로드캐스트 프레임 구조:**

```
[마스터 틱] [종료신호]
```

- 슬롯 0 시작 시점에 TX 케이블을 통해 모든 슬레이브에 동시 전송
- 구체적인 프레임 형식(preamble 포함 여부 등)은 구현 단계에서 확정

### 3.2 시간동기

마스터는 사이클 시작마다 자신의 로컬 카운터 값(틱)을 브로드캐스트한다. 각 슬레이브는 자기 슬롯에서 자신의 로컬 카운터 값을 같은 프레임 위치에 실어 전송한다.

마스터와 슬레이브가 동일한 프레임 내 위치에서 틱을 캡처하면, 두 값의 차이는 슬롯 번호에 따른 고정 오프셋만 남는다. 슬롯 길이(틱 수)가 알려져 있으므로, 슬롯 번호의 정수배를 보정해 두 값을 같은 기준으로 비교할 수 있다.

오프셋 계산은 호스트(PS 또는 상위 로직)가 수행한다.

### 3.3 내고장성

fault를 세 종류로 분류한다:

| 종류 | 조건 |
|------|------|
| 경계위반 (PREAMBLE_ERR) | 슬롯 시작 시 preamble(0x55) 미수신 |
| 문법오류 (FRAME_ERR) | preamble 수신 후 프레임 구조 오류 |
| CRC 오류 (CRC_ERR) | CRC 불일치 |

fault 카운터가 FAULT_TH에 도달하면 해당 노드를 fault 상태로 격리한다. 격리 이후 연속 성공 횟수가 RECOVERY_TH에 도달하면 정상 상태로 복구한다. 임계값은 NODE_CFG 레지스터로 설정 가능하다.

## 5. 마스터 / 슬레이브 구성 비교

마스터와 슬레이브는 CTRL, LINK_CFG, IRQ 구조를 공유하며, 역할에 따라 레지스터 구성이 달라진다.

| 항목 | 마스터 | 슬레이브 |
|------|--------|----------|
| 레지스터 수 | 24개 | 8개 |
| 노드 설정 | NODE_CFG (NODE_CNT, FAULT_TH, RECOVERY_TH) | SLAVE_CFG (SLAVE_ADDR) |
| 데이터 방향 | 수신 전용 (NODE_DATA×8) | 송신 전용 (TX_DATA) |
| 상태 관리 | 노드별 NODE_STATUS×8, GLOBAL_STATUS | RX_STATUS (동기 수신 상태) |
| 타임스탬프 | TX_TICK 1개 (자신이 브로드캐스트한 틱) | TX_TICK 1개 (자신이 전송한 틱) |
| 내고장성 | 노드별 fault 카운터, 격리/복구 | 마스터 동기 프레임 수신 오류 감지 |
| CYCLE_CNT | 있음 | 없음 |
