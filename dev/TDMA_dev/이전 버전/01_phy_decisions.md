# TDMA IP — 물리 계층 설계 결정 근거

> 버전: 0.1
> 작성일: 2026-05-18
> 비고: 테스트 HW 고정 사양(기준 클럭, 케이블 길이, 토폴로지)은 제외. 설계 선택 항목만 기술.

---

## 1. TX / RX 케이블 분리 (단방향 이중 케이블)

**결정**: 마스터↔슬레이브 간 케이블을 TX 전용, RX 전용으로 분리한다.

**근거**:
- 단일 케이블 반이중(half-duplex) 방식은 송수신 전환 타이밍을 명시적으로 제어해야 한다. 전환 지연이 슬롯 타이밍 설계를 복잡하게 만든다.
- 케이블 분리 시 송수신이 물리적으로 독립되어, 마스터 틱 브로드캐스트(TX)와 슬레이브 전송(RX)이 동시에 발생할 수 있다. 사이클 시작 시점에 두 동작을 겹치는 설계가 가능해진다.
- 충돌 방지 로직이 불필요하여 TX/RX 엔진 구현이 단순해진다.

---

## 2. 슬레이브별 점대점 연결 (공유 버스 미사용)

**결정**: 마스터와 각 슬레이브를 개별 케이블 쌍으로 직결한다. 공유 버스를 사용하지 않는다.

**근거**:
- 공유 버스는 여러 드라이버가 동일 선에 연결되므로, 슬롯 외 송신 발생 시 버스 경합으로 드라이버가 파손될 위험이 있다.
- 점대점 구성은 각 슬레이브 회선이 독립적이므로 한 슬레이브의 이상이 다른 슬레이브 통신에 영향을 주지 않는다.
- Open-drain 드라이버나 버스 중재 로직이 불필요하여 회로와 Verilog 구현이 단순해진다.
- TDMA로 슬롯을 분리하더라도, 공유 버스 대비 물리적 격리가 보장되어 내고장성 설계가 명확해진다.

---

## 3. 비트 인코딩: Manchester

**결정**: NRZ 대신 Manchester 인코딩을 사용한다.

**근거**:
- Manchester는 비트 중간에 반드시 전이가 발생하므로 수신 측이 별도 클럭 선 없이 비트 타이밍을 복원할 수 있다(셀프 클로킹).
- 각 노드가 독립 크리스탈 클럭을 사용하는 구성에서, 클럭 복원 없이는 수신 측 샘플링 오류가 발생한다. Manchester가 이를 해소한다.
- NRZ 대비 대역폭을 2배 소모하나, 목표 전송 속도(125 kbps)와 기준 클럭(25 MHz) 기준으로 심볼당 클럭 마진이 충분하여 문제가 없다.
- Verilog 구현 난이도가 낮다. TX는 클럭 반 주기마다 신호를 반전하는 로직, RX는 비트 중간 전이를 감지하는 로직으로 수십 줄 수준에서 구현 가능하다.
- 차동 Manchester, 4B5B 등 대안 대비 인코딩/디코딩 테이블이나 추가 상태가 필요 없어 실습 구현에 가장 적합하다.

---

## 4. 아이들 상태: High / 수신 측 풀다운 저항

**결정**: 라인 아이들 상태를 High로 정의한다. 수신 측에 풀다운 저항을 배치한다.

**근거**:

| 목적        | 설명                                                                                  |
| --------- | ----------------------------------------------------------------------------------- |
| 단선 감지     | 케이블이 끊기면 수신 측 풀다운에 의해 라인이 Low로 내려간다. 아이들(High)과 달라지므로 단선을 fault로 감지할 수 있다.          |
| 프레임 시작 감지 | 아이들 High 상태에서 Low 전이가 발생하면 프레임 시작 신호로 해석할 수 있다. 수신 로직이 단순해진다.                       |
| 송신기 사망 감지 | 송신 노드가 완전히 정지하면 라인이 아이들(High)로 유지된다. 수신 측에서 일정 시간 내 전이가 없을 경우 타임아웃 fault로 처리할 수 있다. |

아이들을 Low로 정의하면 단선과 정상 아이들이 구분되지 않아 위 세 가지 감지 기능이 모두 불가능해진다.
