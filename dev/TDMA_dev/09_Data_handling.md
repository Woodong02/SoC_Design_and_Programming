# 슬레이브의 데이터 입력, 송신과 마스터의 수신 데이터 처리

> 버전: 0.1 · 작성일: 2026-05-29

## 슬레이브의 데이터 입력
    RPS7020TK_User_Manual.pdf 마지막(32) 페이지에 따르면 RPS7020TK에는 AC97 인터페이스를 가진 WM9713 칩이 탑재되었다.
    2개의 Audio 출력 포트와 1개의 Audio 입력 포트를 포함하는데, 슬레이브에서는 입력 포트를 이용한다.
    총 5개의 PL Pin이 존재하는데,
    AC97_RSTn : resetn에 연결
    AC97_SYNC : (스피커 출력시) 48kHz 주기마다 16플럭 폭의 high 펄스를 생성하여 출력, (마이크 입력시) 입력핀으로 선언하여 비트 읽기 시작
    AC97_SDI : 마이크 입력 비트
    AC97_BITCLK : 12.288MHz 클럭을 가짐. rising edge때마다 1비트씩 송/수신하므로 falling edge때마다 샘플링하여 비트를 읽어야 함
    AC97_SDO : 스피커 출력 비트

    스피커 출력을 위해선 수준 높은 동기화와 마진이 필요하므로 추후 검토하고(주 기능이 아니므로)
    SYNC와 BITCLK을 이용하여 마이크 데이터를 수신 후 마스터로의 송신 데이터로 특정 시기에 입력한다.
    

## 마스터의 데이터 출력
    마스터는 DIP_SW를 이용하여 7-segment에 데이터를 표시할 수 있다.
    총 1+3비트의 경우의 수가 존재한다.
    DIP_SW[0]을 통해 7-seg의 표시 숫자가 데이터인지 슬롯의 상태인지를 나타낼 수 있다.
    DIP_SW[0] = 0일 때는 7-seg는 8개의 숫자를 표시할 수 있으므로 각 칸(슬레이브)당 0: 정상 노드, 1: silent 노드, 2: fault 노드, 9: 미동작 노드 (NODE_CNT에 의한)임을 나타낼 수 있다.
    다음은 DIP_SW[1]일 경우이다.
    3비트의 DIP_SW를 이용하여 0~7까지의 상태를 읽을 수 있는데 이를 통해 각 slot_out 데이터 32비트를 16진수를 이용해 8개의 칸에 출력할 수 있다.
    이 때, 8과 B, 0과 D가 겹치므로 A, B, C, D, E, F의 경우 .을 붙여 알파벳임을 나타낸다. 예) 8 B. D. 0
