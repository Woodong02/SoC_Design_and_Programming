> 버전: 0.3

## 1. 프레이밍 (Framing)

### 1.1 프레임 길이 방식

**결정**: 고정 길이 프레임. 종료 신호 필드 없음.

**근거**: 송수신 양쪽이 필드 폭을 사전에 알고 있으므로 수신기는 비트 수만 카운팅하면 된다. 가변 길이 대비 상태 머신이 단순하고 Verilog 구현이 쉽다.

### 1.2 프레임 시작 감지

**결정**: SFD(Start Frame Delimiter) 없음. 비트 카운팅 방식.

**근거**: Manchester 인코딩에서 preamble(0x55)의 규칙적인 파형으로 비트 타이밍을 복원한 뒤 비트를 카운팅한다. 오류는 Hamming이 검출·정정하므로 SFD가 없어도 충분하다. SFD를 추가하면 상태 머신에 단계가 하나 늘어나 복잡도가 증가한다.

### 1.3 비트 순서

**결정**: MSB first.

**근거**: Verilog 시프트 레지스터의 자연스러운 방향(`{reg[N-2:0], new_bit}`)이며, Hamming 비트 위치 계산과도 일관성을 유지한다.

## 2. 프레임 구조

### 2.1 슬레이브 프레임 (슬레이브 → 마스터, 공유 RX 버스)

```
[preamble 8b][addr 3b][payload 32b][TX_TICK 32b][Hamming 8b]
 ←────────────────── 83비트 ──────────────────────────────→
              └────── Hamming 커버 범위 (67비트) ──────────┘
```

| 필드 | 폭 | 설명 |
|------|-----|------|
| preamble | 8비트 | 0x55 고정. Manchester 클럭 복원용 |
| addr | 3비트 | 슬레이브 주소 (0~7). 공유 버스에서 마스터가 송신 슬레이브를 식별하고 슬롯 번호와 대조하여 침범을 감지 |
| payload | 32비트 | 슬레이브 센서 데이터 |
| TX_TICK | 32비트 | 슬레이브 로컬 카운터 타임스탬프 |
| Hamming | 8비트 | SEC-DED Hamming 패리티 (addr + payload + TX_TICK, 67비트 커버) |

공유 버스 구성에서 addr 필드는 단순한 식별자를 넘어, 슬롯 타이밍 오류(한 슬레이브가 다른 슬레이브의 슬롯을 침범)를 검출하는 핵심 수단이다. ADDR_ERR 감지 시 FAULT_CNT를 증가시킨다.

### 2.2 마스터 브로드캐스트 프레임 (마스터 → 슬레이브, TX 케이블)

```
[preamble 8b][HALT_CMD 8b][reserved 27b][TX_TICK 32b][Hamming 8b]
 ←──────────────────────── 83비트 ──────────────────────────────→
              └──────────────── Hamming 커버 범위 (67비트) ──────┘
```

| 필드 | 폭 | 설명 |
|------|----|------|
| preamble | 8비트 | 0x55 고정. Manchester 클럭 복원용 |
| HALT_CMD | 8비트 | 슬레이브 중단 명령 비트맵. bit n=1이면 슬레이브 n에 작업 중단 명령 |
| reserved | 27비트 | 향후 사용 예약. 0으로 전송 |
| TX_TICK | 32비트 | 마스터 로컬 카운터 타임스탬프 |
| Hamming | 8비트 | SEC-DED Hamming 패리티 (HALT_CMD + reserved + TX_TICK, 67비트 커버) |

**근거**: 슬레이브 프레임(83비트)과 총 길이를 통일한다. Hamming 커버 대상(preamble 이후 67비트)이 슬레이브와 동일하므로 마스터·슬레이브가 동일한 Hamming 인코더/디코더 로직을 공유할 수 있다. HALT_CMD는 마스터 HW가 고장 슬레이브에게 중단 명령을 내리는 수단으로, 공유 버스에서 비정상 슬레이브가 버스를 오염시키는 것을 방지한다.

## 3. 오류 검출 및 정정

**결정**: SEC-DED Hamming 코드 (8 패리티 비트).

**근거**: 67비트 데이터(addr+payload+TX_TICK 또는 HALT_CMD+reserved+TX_TICK)에 대해 단일 비트 오류 정정(SEC)에 필요한 패리티 비트는 7비트(2^7=128 ≥ 75). 전체 패리티 비트 1개를 추가하면 8비트로 이중 비트 오류 검출(DED)까지 가능하다(SEC-DED). 기존 16비트 대비 8비트로 줄어들며, 1비트 정정 기능이 추가된다.

마스터와 슬레이브 모두 Hamming 커버 대상이 67비트로 동일하므로 동일한 Hamming 인코더/디코더 로직을 공유한다.

**표준 블록 패딩**: 표준 Hamming(127,120) 블록에 맞추기 위해 67비트 유효 데이터를 120비트 데이터 영역의 앞 67 슬롯에 MSB first로 배치하고, 나머지 53 슬롯을 0으로 패딩한다. 패리티 계산(P1·P2·P4·P8·P16·P32·P64) 후 7 패리티 비트를 추출하고, 전체 패리티 1비트를 추가하여 총 8비트 Hamming 필드를 프레임에 실어 전송한다. 수신 측은 동일한 패딩 규칙으로 신드롬을 계산한다.

**GUARD_TICKS 나누기 처리**: `GUARD_TICKS / 4`는 RTL에서 `>> 2`로 구현된다. 4의 배수가 아닐 경우 하위 2비트가 잘려 내림 처리되며, 이는 의도된 동작이다(임계값이 보수적으로 설정됨).

**Hamming 오류 처리**:
- 1비트 오류: 하드웨어가 자동 정정 후 수신 처리를 계속한다. 정상 수신으로 간주한다.
- 2비트 오류: 검출만 가능, 정정 불가 → HAMMING_ERR 플래그 세팅, FAULT_CNT 증가, 프레임 폐기.

## 4. MAC 부계층

### 4.1 슬롯 길이 자동 계산

슬롯 길이를 사용자가 직접 설정하지 않고 하드웨어가 자동 계산한다. 설정 실수로 인한 슬롯 충돌을 구조적으로 방지한다.

```
frame_ticks = 83 × 2 × (DIV + 1)

slot_ticks  = frame_ticks + GUARD_TICKS
```

계산 결과는 **SLOT_TICKS_RO** (읽기 전용 레지스터)로 노출하여 사용자가 검증할 수 있도록 한다.

### 4.2 Guard Time

**GUARD_TICKS**: 사용자 설정 (RW).

**GUARD_MIN_RO**: 하드웨어 계산 최솟값 (읽기 전용). 사용자가 GUARD_TICKS를 이 값보다 작게 설정하지 않도록 참조 기준을 제공한다.

```
GUARD_MIN = RX_PROCESS_CYCLES + CABLE_DELAY_TICKS + MARGIN
```

케이블 지연은 Verilog 파라미터로부터 계산된다:

```verilog
parameter CABLE_LENGTH_CM   = 50;
parameter CABLE_DELAY_NS    = (CABLE_LENGTH_CM * 5 + 99) / 100; // 5ns/m, 올림
parameter CLK_PERIOD_NS     = 40;                                // 25MHz
parameter CABLE_DELAY_TICKS = (CABLE_DELAY_NS + CLK_PERIOD_NS - 1) / CLK_PERIOD_NS;
// 50cm → 0 ticks (25MHz 기준 전파 지연 < 1클럭)
```

케이블 길이 변경 시 파라미터 하나만 수정하면 GUARD_MIN이 자동으로 반영된다.

공유 버스에서 guard time은 이전 슬레이브의 드라이버가 High-Z로 전환되고 다음 슬레이브의 드라이버가 버스를 구동하기 전까지의 여유 시간을 포함한다. 버스 전환 지연(bus turnaround)이 GUARD_MIN 계산에 반영된다.

### 4.3 슬레이브 슬롯 시작 감지

**기준점**: 마스터 브로드캐스트의 첫 번째 액티브 에지 (High-Z → 드라이버 첫 전이).

```
TX 라인: ─────┐ or ─────/
               └─ ...      ← 이 에지가 사이클 시작 기준
```

슬레이브는 이 에지를 감지한 순간부터 로컬 클럭으로 카운팅을 시작한다.

```
슬롯 시작까지 대기 = SLAVE_ADDR × slot_ticks
```

preamble 수신 및 Hamming 검증은 슬롯 카운터와 **병렬**로 진행된다. 검증 결과가 타이밍을 막지 않는다.

| SLAVE_ADDR | 동작 |
|------------|------|
| 0 | 에지 감지 즉시 송신 시작 (마스터 브로드캐스트와 동시. TX/RX 분리로 충돌 없음) |
| n | 에지로부터 n × slot_ticks 후 송신 시작 |

**브로드캐스트 미수신 시**: 예상 사이클 주기 내에 액티브 에지가 감지되지 않으면 해당 사이클을 스킵하고 SYNC_MISS 플래그를 설정한다. 다음 브로드캐스트를 기다린다.

### 4.4 결함 슬레이브 슬롯 처리

**결정**: fault 상태 슬레이브의 슬롯을 사이클에서 제거하지 않는다. 사이클 주기는 NODE_CNT 기준으로 항상 고정이다.

**근거**: 슬롯을 제거하면 사이클 주기가 가변적이 되어 다른 슬레이브의 타이밍이 흔들린다. 공유 버스에서 모든 슬레이브가 동일한 slot_ticks 기반으로 자신의 슬롯 시작을 계산하므로, 사이클 구조가 변하면 전 슬레이브의 타이밍이 동시에 영향받는다. 마스터는 fault 슬롯에서 RX 윈도우를 열되, 아무것도 수신하지 않으면 그대로 흘려보낸다. 슬롯이 유지되어야 fault 슬레이브의 복구 감지도 가능하다.

### 4.5 초기 기동

| 노드 | 동작 |
|------|------|
| 마스터 | ENABLE 시 즉시 사이클 0 시작, 첫 브로드캐스트 송신 |
| 슬레이브 | 전원 인가 후 TX 라인 모니터링 대기 → 첫 액티브 에지 감지 시 자동 동기 획득 |

별도 핸드셰이크 없이 자연스럽게 동기가 성립한다.
