PL에서는 top module(AXI)에서 DIV+1의 값을 각 모듈의 DIV에 wire로 연결함.
이를 통해 각 모듈에선 1~1024의 DIV값으로 설계할 수 있음

PS의 enable 명령에 대하여
UART통신으로 컴퓨터에서 PS를 통해 Master에 Enable명령 가능
이미 모든 모듈에 if(!resetn)으로 구축된 리셋 기능이 존재함.
if(Enable)와 같은 변수(포트) 다중화보다는 
wire true_resetn = enable? resetn : enable과 같은 형식으로
포트를 늘리지 않으며 resetn의 기능(PL의 버튼을 통한)을 유지하면서 enable의 기능도 유지함.

데이터 이용(선택)
AC97 인터페이스를 가진 WM9713 칩을 이용해 오디오 입/출력 기능 시험
Slave에서 마이크 입력, Master에서 스피커 출력(선택)
오디오 칩에는 따로 12.288MHz의 Oscilator가 있어 항상 클럭 주기마다 1비트씩 데이터를 입/출력함
256bit(256cycle) 동안 입/출력하면 비로소 한 데이터 프레임을 통한 마이크/스피커의 입/출력 사이클이 돌음.
오디오 인터페이스 주파수 = 48kHz
실제 오디오 데이터는 16비트, 나머지 240비트는 제어에 가까우므로 실제 통신하는 데이터는 16비트가 될 듯
통신속도가 2배는 더 빠르게 해서 FIFO ip를 이용해서 딜레이를 주지만 안정적으로 마이크의 입력값을 스피커에 출력하는 과정이 필요해짐
