# TDMA Slave IP — 레지스터 맵 사양

> 버전: 0.1 (초안) · 데이터 폭: 32비트 · 주소 폭: 32비트 · 엔디언: little-endian

---

## 표기 규칙

| 기호 | 의미 |
|------|------|
| RO | 읽기 전용 |
| RW | 읽기/쓰기 |
| W1C | 쓰기 1로 클리어 |
| RC | 읽기로 클리어 |
| reserved | 0으로 읽힘, 쓰기 무시 |

---

## 마스터와의 구성 비교

| 그룹 | 마스터 | 슬레이브 | 비고 |
|------|--------|----------|------|
| CTRL | ENABLE, SOFT_RST | 동일 | 재활용 |
| LINK_CFG | DIV, GUARD_TICKS | 동일 | 재활용, 링크 파라미터는 스타 내 통일 |
| 노드 설정 | NODE_CFG (NODE_CNT, FAULT_TH, RECOVERY_TH) | SLAVE_CFG (SLAVE_ADDR) | 슬레이브는 자신의 주소만 설정 |
| 송신 데이터 | 없음 (수신 전용) | TX_DATA | 슬레이브 → 마스터 방향 payload |
| 수신 데이터 | NODE_DATA[1~7] | 없음 | 마스터만 수신 데이터 보관 |
| 수신 상태 | NODE_STATUS[1~7] | RX_STATUS | 슬레이브는 자기 슬롯 하나만 |
| PTP 타임스탬프 | T1~T4 × 7노드 | T1~T4 × 1 (자기 슬롯) | 슬레이브는 단일 세트 |
| 글로벌 상태 | GLOBAL_STATUS, CYCLE_CNT | 없음 | 마스터 전용 |
| 인터럽트 | IRQ_STATUS, IRQ_MASK | 동일 구조, 이벤트 다름 | 재활용 |

---

## 1. 제어 레지스터

### 0x00 — CTRL

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | ENABLE | RW | 0 | 1: IP 동작 시작 |
| 1 | SOFT_RST | RW | 0 | 1: 소프트 리셋 (자동 클리어) |
| 31:2 | reserved | — | 0 | — |

---

### 0x04 — LINK_CFG

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 9:0 | DIV | RW | 0 | clk_tick = clk / (DIV + 1), 마스터와 동일 값으로 설정 |
| 19:10 | GUARD_TICKS | RW | — | guard time 틱 수, 마스터와 동일 값으로 설정 |
| 31:20 | reserved | — | 0 | — |

> 스타 토폴로지 내 모든 노드는 LINK_CFG를 동일하게 설정해야 한다.

---

### 0x08 — SLAVE_CFG

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 2:0 | SLAVE_ADDR | RW | 0 | 자신의 슬레이브 주소 (1~7, 0은 루프백 예약) |
| 31:3 | reserved | — | 0 | — |

---

## 2. 송신 데이터 레지스터

### 0x0C — TX_DATA

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 31:0 | TX_DATA | RW | 0 | 마스터에게 전송할 payload. 자신의 슬롯 시작 전 PS가 써넣음 |

---

## 3. 수신 상태 레지스터

### 0x10 — RX_STATUS

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | DATA_SENT | W1C | 0 | 1: 해당 슬롯에서 TX_DATA 전송 완료 |
| 1 | CRC_ERR | W1C | 0 | 마스터 답신 CRC 오류 |
| 2 | PREAMBLE_ERR | W1C | 0 | 마스터 답신 preamble 경계위반 |
| 3 | FRAME_ERR | W1C | 0 | 마스터 답신 프레임 오류 |
| 31:4 | reserved | — | 0 | — |

---

## 4. PTP 타임스탬프 레지스터

### 0x14 — T1

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T1 | RO | 슬레이브 송신 타임스탬프 |

### 0x18 — T2

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T2 | RO | 마스터 수신 타임스탬프 (마스터 답신에서 추출) |

### 0x1C — T3

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T3 | RO | 마스터 답신 송신 타임스탬프 (마스터 답신에서 추출) |

### 0x20 — T4

| 비트 | 이름 | 접근 | 설명 |
|------|------|------|------|
| 31:0 | T4 | RO | 슬레이브 수신 타임스탬프 |

> 캡처 지연: T1~T4 모두 실제 이벤트 기준 동일한 N클럭 후 캡처. 차분 계산 시 지연 상쇄됨.
> PTP 보정: offset = ((T2-T1)-(T4-T3))/2, delay = ((T2-T1)+(T4-T3))/2

---

## 5. 인터럽트 레지스터

### 0x24 — IRQ_STATUS

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | SLOT_DONE | W1C | 0 | 자신의 슬롯 1회 완료 |
| 1 | TX_DONE | W1C | 0 | TX_DATA 전송 완료 |
| 2 | RX_ERROR | W1C | 0 | 마스터 답신 수신 오류 (CRC/프레임/preamble) |
| 3 | PTP_DONE | W1C | 0 | PTP 타임스탬프 갱신 완료 |
| 31:4 | reserved | — | 0 | — |

---

### 0x28 — IRQ_MASK

| 비트 | 이름 | 접근 | 초기값 | 설명 |
|------|------|------|--------|------|
| 0 | SLOT_DONE_EN | RW | 0 | 1: SLOT_DONE IRQ 활성화 |
| 1 | TX_DONE_EN | RW | 0 | 1: TX_DONE IRQ 활성화 |
| 2 | RX_ERROR_EN | RW | 0 | 1: RX_ERROR IRQ 활성화 |
| 3 | PTP_DONE_EN | RW | 0 | 1: PTP_DONE IRQ 활성화 |
| 31:4 | reserved | — | 0 | — |

> IRQ 핀 = OR(IRQ_STATUS & IRQ_MASK).

---

## 주소 맵 요약

| 범위 | 그룹 | 레지스터 수 |
|------|------|-------------|
| 0x00 ~ 0x08 | 제어 (CTRL, LINK_CFG, SLAVE_CFG) | 3 |
| 0x0C | 송신 데이터 | 1 |
| 0x10 | 수신 상태 | 1 |
| 0x14 ~ 0x20 | PTP 타임스탬프 | 4 |
| 0x24 ~ 0x28 | 인터럽트 | 2 |
| **합계** | | **11개** |
