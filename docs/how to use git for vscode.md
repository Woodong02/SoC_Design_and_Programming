# 🎨 VS Code에서 Git 더 편리하게 사용하기

VS Code의 내장 기능과 확장 프로그램을 활용하면 Git 관리가 훨씬 쉬워집니다.

git 폴더를 VS Code로 열면 자동으로 Git 관리가 사용 가능합니다.

---

## 1. 좌측 '소스 제어' 탭 활용 (Ctrl + Shift + G)
VS Code 왼쪽 아이콘 중 3번째(가지 모양) 탭에서 모든 작업을 시각적으로 처리할 수 있습니다.

*   **Add (+ 버튼):** 파일명 옆의 + 버튼을 누르면 `git add`와 동일하게 작동합니다.
*   **Commit (체크표시 버튼):** 상단 입력창에 메시지를 적고 체크(✓) 버튼을 누르면 `git commit`이 완료됩니다.
*   **Push/Pull (하단 동기화 아이콘):** 왼쪽 아래 상태 바의 새로고침 모양 아이콘을 누르면 자동으로 Push와 Pull이 진행됩니다.

---

## 2. 클릭으로 해결하는 '충돌 처리'
충돌(Conflict)이 발생하면 VS Code가 파일을 분석하여 상단에 옵션 버튼을 띄워줍니다.

*   **Accept Current Change:** 내 코드를 선택합니다.
*   **Accept Incoming Change:** 서버(동료)의 코드를 선택합니다.
*   **Accept Both Changes:** 두 코드 모두 유지합니다.
> 버튼 하나만 누르면 복잡한 특수 기호(<<<<, ====)가 자동으로 삭제되어 매우 편리합니다.
