# 발표자료 흐름

프로젝트 소개 → TDMA 사양 정의 → TDMA 구현 소개 → TDMA 시연 → 마무리

> 사양 정의와 구현 소개는 빠르게 넘겨 시간을 절약한다.

---

## 1. 프로젝트 소개 (슬라이드 3~6)

RT·안전 → ET가 아니라 TT가 필요 → TT를 SoC로 구현해보았다.

---

## 2. TDMA 사양 정의 (슬라이드 7~14)

1. 물리·데이터링크 계층만 정의
2. 토폴로지, 라인코딩 종류, 단일 드라이버 소개
3. Master/Slave 프레임 구조 소개
4. 동기 방식 → Guard tick과 타임슬롯 → DIV 순으로 소개
5. 흐름 제어 (재전송 없음, 에러 발생 시 버림)

---

## 3. TDMA 구현 소개 (슬라이드 15~29)

**앞부분 — 블록도로 시스템 전체 소개**
- Master: GPIO → PS → PL → Master IP
- Slave: GPIO → PL → Slave IP

**뒷부분 — 세부사항 소개**
- Slave는 여러 슬롯을 시뮬레이션
- Payload는 버튼으로 생성
- Master는 문제 상황에서 카운터를 세어가며 고장 처리
- Slave는 중단 명령을 받으면 중단하며 고장 처리
