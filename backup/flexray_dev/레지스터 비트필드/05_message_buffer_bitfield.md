# 05. 메시지 버퍼 레지스터 비트필드

> 검토 목적: 각 필드의 필요 여부, 버퍼 수 결정, 송수신 방향 설계  
> 블록: mb_ctrl / mb_filter / mb_id / mb_status / mb_tx  
> 주의: POC:config 또는 MB_DIS 상태에서 쓰기 가능

---

## MBCCSRn — Message Buffer Configuration, Control, Status Register

| 비트 | 필드 | R/W | 설명 |
|------|------|-----|------|
| 14 | MCM | R/W | 커밋 모드. 0=즉시, 1=더블버퍼. |
| 13 | MBT | R/W | 버퍼 타입. 0=싱글, 1=더블. |
| 12 | MTD | R/W | 전송 방향. 0=수신(RX), 1=송신(TX). |
| 11 | CMT | R/W | 송신 커밋 트리거. 1을 쓰면 송신 예약. 자동 클리어. |
| 10 | EDT | R/W | 활성화/비활성화 트리거. 1을 쓰면 EDS 토글. |
| 9 | LCKT | R/W | 잠금/해제 트리거. 1을 쓰면 LCKS 토글. |
| 8 | MBIE | R/W | 메시지 버퍼 인터럽트 활성화. |
| 4 | DUP | R | 데이터 업데이트 플래그. 새 데이터 수신 시 세트. |
| 3 | DVAL | R | 데이터 유효 플래그. 유효한 데이터가 버퍼에 있음. |
| 2 | EDS | R | 활성화 상태. 1=활성화. |
| 1 | LCKS | R | 잠금 상태. 1=잠김 (PE가 접근 중). |
| 0 | MBIF | R/W | 메시지 버퍼 인터럽트 플래그. 1을 써서 클리어. |

---

## MBCCFRn — Message Buffer Cycle Counter Filter Register

| 비트 | 필드 | R/W | 설명 |
|------|------|-----|------|
| 15 | MTM | R/W | 송신 모드. 0=단일 송신, 1=연속 송신. |
| 14 | CHA | R/W | 채널 A 할당. 수신 시 채널 A 프레임 수신 여부. |
| 13 | CHB | R/W | 채널 B 할당. 단채널이라 미사용. |
| 12 | CCFE | R/W | 사이클 카운터 필터링 활성화. |
| 11–6 | CCFMSK | R/W | 사이클 카운터 필터 마스크. |
| 5–0 | CCFVAL | R/W | 사이클 카운터 필터 값. |

---

## MBFIDRn — Message Buffer Frame ID Register

| 비트 | 필드 | R/W | 설명 |
|------|------|-----|------|
| 10–0 | FID | R/W | 프레임 ID. 해당 버퍼가 점유하는 슬롯 번호. DIP 스위치 값으로 설정. |

---

## 관련 필드 (타 블록)

### GIFER — 메시지 버퍼 인터럽트 집계 (인터럽트 블록)

| 비트 | 필드 | 설명 |
|------|------|------|
| 9 | RBIF | 수신 버퍼 인터럽트 플래그. MBCCSRn[MTD]=0인 버퍼 중 MBIF+MBIE 동시 세트 시. |
| 8 | TBIF | 송신 버퍼 인터럽트 플래그. MBCCSRn[MTD]=1인 버퍼 중 MBIF+MBIE 동시 세트 시. |
| 1 | RBIE | 수신 버퍼 인터럽트 활성화. |
| 0 | TBIE | 송신 버퍼 인터럽트 활성화. |

### PSR0 — 버퍼 쓰기 가능 상태 확인 (제어/상태 블록)

| 비트 | 필드 | 설명 |
|------|------|------|
| 10–8 | PROTSTATE | 001=config 또는 MB_DIS 상태에서 MBCCSRn/MBCCFRn/MBFIDRn 쓰기 가능. |

### SLTCTAR — 현재 슬롯 번호 (타이밍/카운터 블록)

| 비트 | 필드 | 설명 |
|------|------|------|
| 10–0 | SLOTCNTA | MBFIDRn[FID]와 일치하는 슬롯에서 송수신 발생. |
